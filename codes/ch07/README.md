# 7장 박스오피스 API 앱

영화진흥위원회 KOBIS 오픈API를 실시간으로 호출하는 앱입니다. 인증키는 스트림릿 클라우드 [Settings] - [Secrets]에 `KOBIS_KEY = "발급받은 인증키"`로 등록합니다.

- `main.py` : 1절 일별 박스오피스 (순위표, 당일 관객 수 그래프, 1위 영화 집중도 도넛). 기본 날짜는 한국 시간 기준 어제입니다.
- `pages/00_주간박스오피스.py` : 2절 최근 52주의 주간 박스오피스와 세 가지 분석 (누적 관객 수, 연속 1위 기간, 두 기준 비교)
- `pages/01_역주행영화.py` : 2절 뒤늦게 관객이 늘어난 영화 찾기

KOBIS 오픈API 응답은 저장하거나 다시 배포할 수 없습니다. 이 앱은 받은 응답을 화면에서만 사용하고 파일로 저장하거나 내려받게 하지 않으며, 같은 요청을 반복하지 않도록 10분 동안만 기억합니다. `st.dataframe`으로 그린 표에는 CSV 내려받기 메뉴가 기본으로 붙으므로, 응답을 보여 주는 표는 내려받기 메뉴가 없는 정적 표(`st.table`)로 그립니다. 52주를 합친 표처럼 행이 많은 표는 높이를 정한 영역 안에서 스크롤해 확인합니다.
